# tplinkeasysmart_led (Resource)

The front-panel LEDs of the switch (System > LED On/Off in the web UI). There is exactly one per switch; import it with the id `led`. Destroying the resource only removes it from state and leaves the LEDs as they are.

## Example Usage

```terraform
# The front-panel LEDs of the switch.
resource "tplinkeasysmart_led" "this" {
  enabled = true
}
```
