# tplinkeasysmart_led (Resource)

The front-panel LEDs of the switch (System > LED On/Off in the web UI). There is exactly one per switch; import it with the id `led`. Destroying the resource only removes it from state and leaves the LEDs as they are.

## Example Usage

```terraform
# The front-panel LEDs of the switch.
resource "tplinkeasysmart_led" "this" {
  enabled = true
}
```

## Schema

### Required

- `enabled` (Boolean) Whether the port LEDs are on.

### Optional

- `switch` (String) Name of the switch (a key of the provider's `switches` map) this object lives on. Required when the provider has a `switches` map; `default` is the provider's own switch (`host`) beside it. Omit it when the provider has only its own switch. Changing it replaces the resource.

### Read-Only

- `id` (String) Always `led`.

## Import

Import is supported using the following syntax:

```shell
terraform import tplinkeasysmart_led.this led
```

For a switch defined in the provider's `switches` map, put the switch name in front of the id, separated by a colon (for example `sw02:7` or `sw02:led`). Without a prefix the id belongs to the provider's own switch (`host`); when the provider has a `switches` map, always give a prefix, `default:` for the provider's own switch (for example `default:7`).
