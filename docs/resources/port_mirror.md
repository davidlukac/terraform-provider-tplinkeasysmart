# tplinkeasysmart_port_mirror (Resource)

Port mirroring (Monitoring > Port Mirror). Singleton; import with id `port_mirror`. **Safety:** the destination port stops carrying normal traffic, so by default the provider refuses a destination that has a link up or is in a LAG; set `allow_disruptive = true` to override. Destroying only removes it from state.

~> **Safety** The destination port stops carrying normal traffic. The provider refuses a destination port that has a link up or belongs to a LAG unless `allow_disruptive = true`.

## Example Usage

```terraform
# Mirror port 4's received traffic to the free port 7.
resource "tplinkeasysmart_port_mirror" "this" {
  enabled       = true
  mirror_port   = 7
  ingress_ports = [4]

  # Safety: the destination port stops carrying normal traffic. The provider
  # refuses a destination that has a link up or is in a LAG unless overridden.
  # allow_disruptive = true
}
```

## Schema

### Required

- `enabled` (Boolean) Whether mirroring is enabled. When false, no other port setting may be given.

### Optional

- `allow_disruptive` (Boolean) Allow a destination port that has a link up or is a LAG member. Defaults to false.
- `egress_ports` (Set of Number) Ports whose transmitted traffic is mirrored.
- `ingress_ports` (Set of Number) Ports whose received traffic is mirrored.
- `mirror_port` (Number) Destination (monitoring) port; 0 when disabled.

### Read-Only

- `id` (String) Always `port_mirror`.
