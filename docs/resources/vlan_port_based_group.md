# tplinkeasysmart_vlan_port_based_group (Resource)

A port-based VLAN group (VLAN > Port Based VLAN). Import with the VLAN id. The VLAN **mode** is not managed here. The id must be one the switch has (1 to the number of groups it supports, 8 on a TL-SG108E; see the `tplinkeasysmart_vlan_port_based` data source) and is checked before anything is written; creating a group that already exists is refused (import it instead). Membership is exclusive: adding ports to a group removes them from their previous group, and removing a group returns its ports to VLAN 1. **Safety:** the provider refuses to create, change or destroy a group when any port involved (old or new members) has a link up or belongs to a LAG, because that can cut connectivity or management access; set `allow_disruptive = true` to override. Import VLAN 1 (the default group) only together with `lifecycle { prevent_destroy = true }`.

~> **Safety** The provider refuses to create, change or destroy a group when any port involved (old or new members) has a link up or belongs to a LAG, because VLAN membership is exclusive and a change moves the port out of its previous group. The VLAN mode itself is not written here; use `tplinkeasysmart_vlan_mode`.

~> **If the VLAN mode changes behind Terraform's back** a refresh no longer fails: it warns that the {x} cannot be read while another VLAN mode is active and keeps the resource's state as it is (changes stay refused until the mode is switched back). Removing the resource from the configuration then only forgets it.

## Example Usage

```terraform
# Only valid while the switch is in port-based VLAN mode (see tplinkeasysmart_vlan_mode). Membership is exclusive: the ports leave their previous group
# (VLAN 1) and return to it when this group is destroyed.
resource "tplinkeasysmart_vlan_port_based_group" "lab" {
  vlan  = 2
  ports = [6, 7]
}
```

## Schema

### Required

- `ports` (Set of Number) Member ports (at least one).
- `vlan` (Number) VLAN group id.

### Optional

- `allow_disruptive` (Boolean) Allow touching ports that have a link up or belong to a LAG. Defaults to false.
- `switch` (String) Name of the switch (a key of the provider's `switches` map) this object lives on. Omit it to use the provider's own switch (`host`), or the only configured switch. Changing it replaces the resource.

## Import

Import is supported using the following syntax:

```shell
# The import id is the VLAN id.
terraform import tplinkeasysmart_vlan_port_based_group.lab 2
```

For a switch defined in the provider's `switches` map, put the switch name in front of the id, separated by a colon (for example `sw02:7` or `sw02:led`). Without a prefix the id belongs to the provider's own switch (`host`).
