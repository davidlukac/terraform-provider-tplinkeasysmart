# tplinkeasysmart_loop_prevention (Resource)

Loop prevention (Monitoring > Loop Prevention). Singleton; import with id `loop_prevention`. Keep it enabled on a production network. Destroying only removes it from state.

## Example Usage

```terraform
# Keep loop prevention enabled on a production network.
resource "tplinkeasysmart_loop_prevention" "this" {
  enabled = true
}
```

## Import

Import is supported using the following syntax:

```shell
terraform import tplinkeasysmart_loop_prevention.this loop_prevention
```

For a switch defined in the provider's `switches` map, put the switch name in front of the id, separated by a colon (for example `sw02:7` or `sw02:led`). Without a prefix the id belongs to the provider's own switch (`host`).
