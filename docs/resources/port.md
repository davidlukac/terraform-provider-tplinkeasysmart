# tplinkeasysmart_port (Resource)

Configuration of one physical port (Switching > Port Setting): admin state, speed and flow control. Import with the port number. **Safety:** by default the provider refuses to change a port that has a link up or is in a LAG, because that can cut the uplink or the management path; set `allow_disruptive = true` to override. Destroying only removes it from state.

~> **Safety** The provider refuses to change a port that has a link up or belongs to a LAG unless `allow_disruptive = true`. Disabling or re-negotiating the port that carries Terraform's own connection, or the LAG to the router, cuts access to the switch and needs a physical reset to recover.

## Example Usage

```terraform
# Port 7 is not cabled in this example.
resource "tplinkeasysmart_port" "unused" {
  port         = 7
  speed        = "auto"
  flow_control = false

  # Safety: by default the provider refuses to change a port that has a link up
  # or belongs to a LAG, because that can cut the uplink or the management path.
  # Only set this after checking the port is not needed for connectivity.
  # allow_disruptive = true
}
```

## Schema

### Required

- `port` (Number) Port number (1-based).

### Optional

- `allow_disruptive` (Boolean) Allow changing a port that has a link up or is a LAG member. Defaults to false.
- `enabled` (Boolean) Administrative state. Defaults to true.
- `flow_control` (Boolean) Flow control. Defaults to false. It can be true only with speed `auto` or `1000Mbps-full`: at a fixed 10 or 100 Mbps speed the switch accepts the setting but keeps flow control off, so that combination is refused while planning.
- `speed` (String) One of: auto, 10Mbps-half, 10Mbps-full, 100Mbps-half, 100Mbps-full, 1000Mbps-full. Defaults to auto.
- `switch` (String) Name of the switch (a key of the provider's `switches` map) this object lives on. Omit it to use the provider's own switch (`host`), or the only configured switch. Changing it replaces the resource.

### Read-Only

- `actual_speed` (String) Currently negotiated speed, or link-down.

## Import

Import is supported using the following syntax:

```shell
# The import id is the port number.
terraform import tplinkeasysmart_port.unused 7
```

For a switch defined in the provider's `switches` map, put the switch name in front of the id, separated by a colon (for example `sw02:7` or `sw02:led`). Without a prefix the id belongs to the provider's own switch (`host`).
