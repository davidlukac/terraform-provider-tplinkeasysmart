# tplinkeasysmart_vlan_8021q_group (Resource)

An 802.1Q VLAN (VLAN > 802.1Q VLAN): its name and its tagged and untagged member ports. Import with the VLAN id. The 802.1Q mode must already be active (see `tplinkeasysmart_vlan_mode`); the provider refuses to manage VLANs in another mode. Unlike port-based groups, a port can be a member of several 802.1Q VLANs. **Safety:** the provider refuses to create, change or destroy a VLAN when any port involved (old or new members) has a link up or belongs to a LAG, and when the change would leave a port in no VLAN at all, because that can cut connectivity or management access; set `allow_disruptive = true` to override. Keep VLAN 1 (the default) under `lifecycle { prevent_destroy = true }`.

~> **Safety** The provider refuses to create, change or destroy a VLAN when any port involved (old or new members) has a link up or belongs to a LAG, and when the change would leave a port in no VLAN, because that can cut connectivity or management access. The VLAN mode is not written here; use `tplinkeasysmart_vlan_mode`.

~> **Order** Terraform cannot see that this resource needs the switch to be in 802.1Q mode first, and the provider refuses to manage 802.1Q VLANs in any other mode. When one configuration sets the mode and the VLANs, add `depends_on = [tplinkeasysmart_vlan_mode.this]` (see the example) so the mode is applied first and, on the way back, removed last.

## Example Usage

```terraform
# Only valid while the switch is in 802.1Q mode (see tplinkeasysmart_vlan_mode), so the
# VLAN waits for the mode resource: Terraform cannot see that dependency by itself.
resource "tplinkeasysmart_vlan_mode" "this" {
  mode             = "802.1q"
  allow_disruptive = true # needed for the change itself; remove it once the switch is in the mode
}

# A port can be a member of several 802.1Q VLANs, tagged in some and untagged in others.
resource "tplinkeasysmart_vlan_8021q_group" "media" {
  vlan           = 20
  name           = "media"
  tagged_ports   = [5]
  untagged_ports = [6, 7]

  depends_on = [tplinkeasysmart_vlan_mode.this]
}
```

## Schema

### Required

- `vlan` (Number) VLAN id, 1-4094.

### Optional

- `allow_disruptive` (Boolean) Allow touching ports that have a link up or belong to a LAG, and leaving a port in no VLAN. Defaults to false.
- `name` (String) VLAN name, up to 10 letters, digits, hyphens or underscores. Defaults to empty.
- `switch` (String) Name of the switch (a key of the provider's `switches` map) this object lives on. Omit it to use the provider's own switch (`host`), or the only configured switch. Changing it replaces the resource.
- `tagged_ports` (Set of Number) Ports that carry this VLAN tagged. Defaults to none.
- `untagged_ports` (Set of Number) Ports that carry this VLAN untagged. Defaults to none.

## Import

Import is supported using the following syntax:

```shell
# The import id is the VLAN id.
terraform import tplinkeasysmart_vlan_8021q_group.media 20
```

For a switch defined in the provider's `switches` map, put the switch name in front of the id, separated by a colon (for example `sw02:7` or `sw02:led`). Without a prefix the id belongs to the provider's own switch (`host`).
