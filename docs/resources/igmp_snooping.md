# tplinkeasysmart_igmp_snooping (Resource)

IGMP snooping (Switching > IGMP Snooping). Singleton; import with id `igmp_snooping`. Destroying only removes it from state. With snooping off, multicast is flooded to all ports.

## Example Usage

```terraform
resource "tplinkeasysmart_igmp_snooping" "this" {
  enabled                    = true
  report_message_suppression = false
}
```

## Import

Import is supported using the following syntax:

```shell
terraform import tplinkeasysmart_igmp_snooping.this igmp_snooping
```

For a switch defined in the provider's `switches` map, put the switch name in front of the id, separated by a colon (for example `sw02:7` or `sw02:led`). Without a prefix the id belongs to the provider's own switch (`host`).
