# tplinkeasysmart_bandwidth_limit (Resource)

Rate limits of one port (QoS > Bandwidth Control). Import with the port number. **Safety:** a limit throttles the port, so by default the provider refuses to change a port that has a link up or is in a LAG; set `allow_disruptive = true` to override. Destroying only removes it from state. **One limiter per port:** the switch keeps either an ingress limit or storm control on a port (writing one turns the other off without a word), so an `ingress_kbps` other than 0 is refused while storm control is on for the port, before anything is written. To change over, turn storm control off with `tplinkeasysmart_storm_limit` first and make this resource `depends_on` it, so that the applies run in that order (without an order, one of the two can be refused). The egress limit is independent of both. Verified on firmware 20230218 and 20250710.

~> **Safety** A limit throttles the port. The provider refuses to change a port that has a link up or belongs to a LAG unless `allow_disruptive = true`.

## Example Usage

```terraform
resource "tplinkeasysmart_bandwidth_limit" "unused" {
  port         = 7
  ingress_kbps = 10240 # multiple of 64, 0 = unlimited
  egress_kbps  = 0

  # Safety: by default the provider refuses to change a port that has a link up
  # or belongs to a LAG, because that can cut the uplink or the management path.
  # Only set this after checking the port is not needed for connectivity.
  # allow_disruptive = true
}
```

## Schema

### Required

- `port` (Number) Port number (1-based).

### Optional

- `allow_disruptive` (Boolean) Allow changing a port that has a link up or is a LAG member. Defaults to false.
- `egress_kbps` (Number) Egress limit in kbps: 0 (unlimited) or a multiple of 64 up to 1000000.
- `ingress_kbps` (Number) Ingress limit in kbps: 0 (unlimited) or a multiple of 64 up to 1000000.
- `switch` (String) Name of the switch (a key of the provider's `switches` map) this object lives on. Omit it to use the provider's own switch (`host`), or the only configured switch. Changing it replaces the resource.

## Import

Import is supported using the following syntax:

```shell
# The import id is the port number.
terraform import tplinkeasysmart_bandwidth_limit.unused 7
```

For a switch defined in the provider's `switches` map, put the switch name in front of the id, separated by a colon (for example `sw02:7` or `sw02:led`). Without a prefix the id belongs to the provider's own switch (`host`).
