# tplinkeasysmart_vlan_8021q_pvid (Resource)

The PVID of one port (VLAN > 802.1Q PVID Setting): the VLAN that untagged traffic entering the port is assigned to. Import with the port number. The 802.1Q mode must be active and the VLAN must exist (see `tplinkeasysmart_vlan_mode` and `tplinkeasysmart_vlan_8021q_group`). **Safety:** the provider refuses to change a port that has a link up or is in a LAG, because a wrong PVID drops the port's untagged traffic; set `allow_disruptive = true` to override. Destroying sets the PVID back to 1 (when 802.1Q is active and VLAN 1 exists), under the same guard.

~> **Safety** The provider refuses to change the PVID of a port that has a link up or belongs to a LAG, because untagged traffic that enters the port is assigned to the new VLAN and may no longer reach its destination. Destroying the resource sets the PVID back to 1, under the same guard.

~> **Order** Terraform cannot see that a PVID needs the switch to be in 802.1Q mode and the VLAN to exist, and the provider refuses otherwise. When one configuration sets them all, add `depends_on` the `tplinkeasysmart_vlan_mode` resource and reference the VLAN's `vlan` attribute from `pvid`. To remove them, put the PVID back to 1 by configuration first: removing the resource only forgets the port's value, and a VLAN cannot be deleted while a port still has it as its PVID.

## Example Usage

```terraform
# Untagged traffic entering port 6 belongs to VLAN 20. The VLAN must exist
# (see tplinkeasysmart_vlan_8021q_group, for example by referencing its `vlan`
# attribute) and the switch must be in 802.1Q mode.
resource "tplinkeasysmart_vlan_8021q_pvid" "media_port" {
  port = 6
  pvid = 20
}
```

### Required

- `port` (Number) Port number (1-based).
- `pvid` (Number) The port's default VLAN id, 1-4094.

### Optional

- `allow_disruptive` (Boolean) Allow changing a port that has a link up or is a LAG member. Defaults to false.
- `switch` (String) Name of the switch (a key of the provider's `switches` map) this object lives on. Omit it to use the provider's own switch (`host`), or the only configured switch. Changing it replaces the resource.

## Import

Import is supported using the following syntax:

```shell
# The import id is the port number.
terraform import tplinkeasysmart_vlan_8021q_pvid.media_port 6
```

For a switch defined in the provider's `switches` map, put the switch name in front of the id, separated by a colon (for example `sw02:7` or `sw02:led`). Without a prefix the id belongs to the provider's own switch (`host`).
