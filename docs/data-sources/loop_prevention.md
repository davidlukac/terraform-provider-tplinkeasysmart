# tplinkeasysmart_loop_prevention (Data Source)

Whether loop prevention is enabled on the switch (Monitoring > Loop Prevention). Read-only; set it with the `tplinkeasysmart_loop_prevention` resource.

## Example Usage

```terraform
data "tplinkeasysmart_loop_prevention" "this" {}

output "loop_prevention_enabled" {
  value = data.tplinkeasysmart_loop_prevention.this.enabled
```
