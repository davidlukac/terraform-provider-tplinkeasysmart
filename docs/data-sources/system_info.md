# tplinkeasysmart_system_info (Data Source)

Identity and network settings of the switch, read through unauthenticated discovery. Also serves as a connectivity check.

## Example Usage

```terraform
data "tplinkeasysmart_system_info" "this" {}

output "switch" {
  value = {
    model    = data.tplinkeasysmart_system_info.this.model
    firmware = data.tplinkeasysmart_system_info.this.firmware_version
    mac      = data.tplinkeasysmart_system_info.this.mac_address
  }
}
```

### Optional

- `switch` (String) Name of the switch (a key of the provider's `switches` map) this object lives on. Omit it to use the provider's own switch (`host`), or the only configured switch.
