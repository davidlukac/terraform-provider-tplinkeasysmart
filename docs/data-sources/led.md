# tplinkeasysmart_led (Data Source)

Whether the front-panel LEDs of the switch are on (System > LED On/Off in the web UI). Read-only; set it with the `tplinkeasysmart_led` resource.

## Example Usage

```terraform
data "tplinkeasysmart_led" "this" {}

output "leds_on" {
  value = data.tplinkeasysmart_led.this.enabled
}
```
