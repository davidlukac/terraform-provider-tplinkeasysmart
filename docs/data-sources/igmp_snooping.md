# tplinkeasysmart_igmp_snooping (Data Source)

IGMP snooping settings and the multicast groups the switch has learned (Switching > IGMP Snooping). Read-only; the groups change at runtime, so keep them out of anything compared between plans. Set the two switches with the `tplinkeasysmart_igmp_snooping` resource.

## Example Usage

```terraform
data "tplinkeasysmart_igmp_snooping" "this" {}

output "multicast_groups" {
  value = { for g in data.tplinkeasysmart_igmp_snooping.this.multicast_groups : g.ip => g.ports }
}
```
