# tplinkeasysmart_bandwidth_control (Data Source)

Per-port rate limits (QoS > Bandwidth Control). Read-only: a wrong limit on an uplink slows or cuts management access.

## Example Usage

```terraform
data "tplinkeasysmart_bandwidth_control" "this" {}

output "limits" {
  value = [for p in data.tplinkeasysmart_bandwidth_control.this.ports : "${p.port}: in=${p.ingress_kbps} out=${p.egress_kbps}"]
}
```
