# tplinkeasysmart_port_statistics (Data Source)

Per-port traffic counters (Monitoring > Port Statistics). Read-only; values change on every read, so do not use them in resource arguments. Counters are 32-bit and wrap.

## Example Usage

```terraform
data "tplinkeasysmart_port_statistics" "this" {}

output "rx_bad" {
  value = { for p in data.tplinkeasysmart_port_statistics.this.ports : p.port => p.rx_bad_packets }
}
```

## Schema

### Optional

- `switch` (String) Name of the switch (a key of the provider's `switches` map) this object lives on. Required when the provider has a `switches` map; `default` is the provider's own switch (`host`) beside it. Omit it when the provider has only its own switch.

### Read-Only

- `id` (String) Always `port_statistics`.
- `ports` (Attributes List) Traffic counters of every port. They change on every read, so keep them out of anything compared between plans. (see [below for nested schema](#nestedatt--ports))
